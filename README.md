## 📖 项目背景与定位

传统高校校园管理长期面临**设施责任不清、部门协同低效、报修流程冗长、数据孤岛严重**等痛点。数智星图以**校园设施责任归属知识图谱**为核心，构建了一套覆盖"学生报修 → 智能派单 → 维修闭环 → 数据沉淀 → 决策优化"全链路的 AI 驱动校园运营中枢。

平台内置 AI Agent「**白泽**」，实现自然语言交互、智能工单分派、风险预警、知识图谱推理等能力，让校园管理从"人找事"变为"事找人"。

> 📌 本项目为挑战杯 / 创新创业竞赛参赛作品，内置完整角色权限体系与脱敏模拟数据，`docker run` 即可体验全流程。

## ✨ 核心优势

### 🏗️ 首创：校园设施责任归属知识图谱

- **责任关系图谱化**：将"建筑 → 楼层 → 设施 → 部门 → 责任人"关系建模为图结构
- **智能派单**：基于责任图谱自动匹配维修人员，派单准确率大幅提升
- **责任追溯**：每一处设施都有明确的责任主体，杜绝推诿
- **可视化探索**：React Flow 交互式图谱，一键查看设施归属网络

### 🤖 AI Agent「白泽」全场景赋能

| AI 能力 | 场景 |
|---------|------|
| 🗣️ 自然语言对话 | 学生用大白话说"宿舍灯坏了"，自动识别为报修工单 |
| 🧠 意图识别 | 智能区分报修、咨询、查询、投诉等意图 |
| 📋 工单推荐 | 根据故障类型、位置、人员负载自动推荐最优处理人 |
| 🔍 知识检索 | 政策问答、校园指南、常见问题智能解答 |
| ⚠️ 风险预警 | 异常报修频率、重复故障自动预警 |
| 🔄 多轮对话 | 支持上下文记忆，持续跟进工单进度 |

### 👥 全角色协同（17+ 岗位）

```
学生 → 报修提交、进度查询、失物招领
辅导员 → 学生管理、宿舍检查、异常关注
院系管理员 → 教学安排、教室调度、卫生评比
后勤负责人 → 工单调度、维修派单、备件管理
维修人员 → 接单处理、完工反馈、维修记录
宿管阿姨 → 宿舍管理、夜查记录、访客登记
超级管理员 → 全局配置、权限管理、数据大屏
```

### 📊 数据驱动决策

- **实时数据大屏**：报修量、处理率、满意度、能耗趋势一屏掌控
- **多维度统计**：按院系、按设施类型、按时间维度分析
- **信用评价体系**：维修人员绩效考核、学生行为积分
- **CIAC 监管级看板**：排名监控、遗漏追踪、异常预警

## 🚀 快速开始

### 一键 Docker 运行（推荐）

```bash
# 拉取镜像
docker pull ghcr.io/a2-del/shuzhi:latest

# 启动容器
docker run -d -p 3000:3000 ghcr.io/a2-del/shuzhi:latest

# 浏览器访问
open http://localhost:3000
```

**演示账号**（登录页可一键选择）：

| 用户名 | 角色视角 | 体验重点 |
|--------|----------|----------|
| `admin` | 超级管理员 | 全局数据大屏、系统配置 |
| `counselor` | 辅导员 | 学生管理、宿舍检查 |
| `logistics` | 后勤负责人 | 工单调度、派单管理 |
| `student` | 学生 | 提交报修、查看进度 |

> 🔑 所有演示账号密码统一为：`123456`

### 从源码构建

```bash
git clone https://github.com/a2-DEL/shuzhi-campus.git
cd shuzhi-campus
pnpm install
pnpm dev
```
